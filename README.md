
## 🚀 Funcionalidades

* **Validação de Formato:** Verifica se a entrada contém a quantidade correta de dígitos.
* **Cálculo de Dígitos Verificadores:** Aplica as regras matemáticas de validação para o primeiro e segundo dígito.
* **Detecção de Números Repetidos:** Identifica e rejeita CPFs com todos os números iguais (ex: `111.111.111-11`), que são matematicamente válidos pelo algoritmo, mas inválidos na receita.

* **Paradigma:** Orientação a Objetos / Funcional
